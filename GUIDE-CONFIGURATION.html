PWA parents, installation Android, aide iPhone/iPad, service worker Push, interface /admin/, backend Supabase, aucune clé privée dans le frontend.

Reste à configurer

  1. Créer un projet Supabase Free.
  2. Exécuter supabase/sql/schema.sql.
  3. Activer Email/Password et créer le compte admin.
  4. Générer les clés VAPID.
  5. Compléter config.js.
  6. Déployer la fonction send-push et ses secrets.
  7. Publier sur GitHub Pages.
  8. Tester Android puis iPhone/iPad.
